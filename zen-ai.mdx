# Zen AI Overview

This overview highlights the connection of Actian VectorAI DB to support in Zen v17 for vector data, released as Zen v17 AI. Zen v17 AI editions incorporate VectorAI DB functionality in the Vector Data Engine. Since the Vector Data Engine presents the same access ports as VectorAI DB, it shares client SDKs with Zen v17 AI.

Accordingly, Zen v17 AI can use the VectorAI DB [dashboard](https://docs.vectoraidb.actian.com/docs/guides/gui-interface) for vector capacity licensing and management. For Zen v17 AI, this dashboard is installed as a service on both Windows and Linux. On Windows systems, Zen installation is all that is required for dashboard use. On Linux, node.js must be installed and available for all users.

For Zen v17 AI installations, the default vector count limit is 1M, so long as a valid Zen engine license is active. As with VectorAI DB, you can increase the available vector count for the Vector Data Engine by [applying licenses](https://docs.vectoraidb.actian.com/home/getting-started/license-activation) using the License Manager in the dashboard.

In Zen v17 AI, you can use Zen SQL to [create and access vector collections](https://docs.actian.com/zen/v17/sqlref/vectorcollectionfuncs.htm). Search results can be used directly or joined with data from traditional tables.
