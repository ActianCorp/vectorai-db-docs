The Zen v17 AI editions incorporate the VectorAI DB functionality as the Vector Data Engine.

The Vector Data Engine presents the same access ports as VectorAI DB and so VectorAI DB client SDKs will work with Zen v17 AI.

The Vector Dashboard is installed as a service on both Windows and Linux. The Windows install includes the necessary pre-requisites. On Linux node.js must be installed and available for all users.

The default vector count limit for the Vector Data Engine is 1M, so long as a valid Zen engine license is active. The vector count may be increased by applying licenses via the Dashboard.

Vector collections may also be accessed from Zen SQL, and search results can be used directly or joined with traditional tables.
