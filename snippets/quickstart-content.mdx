Use this quickstart to run VectorAI DB locally, create a collection, insert sample points, and run a similarity search with the Python SDK.

## Install the SDK

### Prerequisites

<Prerequisites />

Install the Python SDK.

```bash
pip install actian-vectorai-client
```

## Run VectorAI DB

Download and run the VectorAI DB Docker container.

```bash
docker pull actian/vectorai:latest
docker run -d --name vectorai \
  -v ./local_data:/var/lib/actian-vectorai \
  -p 6573-6575:6573-6575 \
  -e ACTIAN_VECTORAI_ACCEPT_EULA=YES \
  actian/vectorai:latest
```

The REST API runs on `localhost:6573`, gRPC runs on `localhost:6574`, and Local UI runs on `localhost:6575`.

## Create a collection

Use the SDK to connect over gRPC and create a collection named `products`.

<Tabs>
  <Tab title="Synchronous">
    ```python
    from actian_vectorai import VectorAIClient, VectorParams, Distance

    with VectorAIClient("localhost:6574") as client:
        info = client.health_check()
        print(f"Connected to {info['title']} v{info['version']}")

        client.collections.create(
            "products",
            vectors_config=VectorParams(size=128, distance=Distance.Cosine),
        )
    ```
  </Tab>
  <Tab title="Asynchronous">
    ```python
    import asyncio
    from actian_vectorai import AsyncVectorAIClient, VectorParams, Distance

    async def main():
        async with AsyncVectorAIClient("localhost:6574") as client:
            info = await client.health_check()
            print(f"Connected to {info['title']} v{info['version']}")

            await client.collections.create(
                "products",
                vectors_config=VectorParams(size=128, distance=Distance.Cosine),
            )

    asyncio.run(main())
    ```
  </Tab>
</Tabs>

## Insert vectors

Generate sample product records and upsert them as points.

```python
import random
from actian_vectorai import PointStruct, VectorAIClient

def generate_sample_products(num_products: int = 100, dimension: int = 128):
    categories = ["electronics", "clothing", "food"]
    points = []

    for i in range(num_products):
        points.append(
            PointStruct(
                id=i,
                vector=[random.gauss(0, 1) for _ in range(dimension)],
                payload={
                    "id": i,
                    "category": categories[i % 3],
                    "price": round(i * 10 + random.random() * 100, 2),
                    "in_stock": i % 2 == 0,
                },
            )
        )

    return points

with VectorAIClient("localhost:6574") as client:
    points = generate_sample_products()
    client.points.upsert("products", points)
    print(f"Inserted {len(points)} vectors")
```

## Search

Search for the five nearest points and retrieve the top match with payload.

```python
import random
from actian_vectorai import VectorAIClient

DIMENSION = 128

with VectorAIClient("localhost:6574") as client:
    query = [random.gauss(0, 1) for _ in range(DIMENSION)]
    results = client.points.search("products", vector=query, limit=5)

    for i, result in enumerate(results, start=1):
        print(f"[{i}] ID: {result.id}, Score: {result.score:.4f}")

    top = client.points.get("products", ids=[results[0].id])[0]
    print(f"Top result payload: {top.payload}")
```

## Clean up

Delete the collection when you are finished.

```python
from actian_vectorai import VectorAIClient

with VectorAIClient("localhost:6574") as client:
    client.collections.delete("products")
```
