## Support for Purchased Licenses

The **Actian Customer Portal** provides 24×7 online support access for customers who have purchased VectorAI DB licenses. Through the portal you can:

- Open support tickets
- Check the status of and update existing issues
- Search the Actian Knowledge Base and forums
- Submit product improvement ideas via the **Idea Center**

<Note>
  To participate in the Actian Customer Portal and file tickets, you must [register for an Actian account](https://www.actian.com/register).
</Note>

## User Registration

Follow these steps to get up and running with your Actian account and VectorAI DB support access.

<Steps>
  <Step title="Register for an Actian Account">
    If you have not done so already, [register for an Actian account](https://www.actian.com/register) using your account number to gain access to the Actian Customer Portal.
  </Step>
  <Step title="Download the Latest Patch">
    When working on-premises, download the latest certified patch from [Actian's Electronic Software Distribution site](https://esd.actian.com).
  </Step>
  <Step title="Open a Support Case">
    Open VectorAI DB support cases within the Actian Customer Portal using the **Case** menu option at the top of the portal.
  </Step>
</Steps>
