## Prerequisites

Before installing, ensure you have:
- At least 8 GB RAM (16 GB+ recommended)
- 10 GB disk space (100 GB+ recommended)


Here are the installation steps:

Prerequisites - Run on a Linux system with systemd. Ensure Node.js 20+, tar, unzip, and libatomic are installed before running the installer.

Extract the tarball - Extract Actian-VectorAI-linux-{arch}-{version}.tar.gz to a working directory. The install subdirectory inside contains the installer script and the bundled packages.

Run as root or with sudo - The installer must be run as root or with a user account that has sudo access. It will prompt for sudo credentials if not already root:

sudo bash actian-vectorai/install/install_actian_vectorai.sh
Accept the EULA - You will be prompted interactively. To skip the prompt (e.g. in automated environments):

sudo ACCEPT_ACTIAN_VECTORAI_EULA=YES bash actian-vectorai/install/install_actian_vectorai.sh
Installation target is /usr/local/actian-vectorai - The installer extracts the core engine and web UI to /usr/local/actian-vectorai. This path is fixed and requires write access to /usr/local, which is why a privileged account is needed.

Data directory defaults to /var/lib/actian-vectorai - Override with ACTIAN_VECTORAI_DATA_DIR=/your/path if needed.

Services are registered and started automatically - Two systemd services are installed and enabled: actian-vectorai.service (gRPC engine on port 6573) and actian-vectorai-webui.service (web UI on port 6575).


Installing on Linux or Raspbian

Follow these command-line instructions to install the Zen Server on Linux-based systems.

### Steps to Install
1.  **Log in** as the `root` user.
2.  **Change** to the `/usr/local` directory:
    ```bash
    cd /usr/local
    ```
3.  **Copy the .tar file** to `/usr/local`.  
    *Example (if downloaded to `/home/bholly`):*
    ```bash
    cp /home/bholly/<server_package_name> .
    ```
4.  **Unpack the .tar file**:
    ```bash
    tar -zxf <server_package_name>
    ```
5.  **Navigate** to the installation scripts folder:
    ```bash
    cd actianzen/etc
    ```
6.  **Run the installation script**:
    ```bash
    ./install.sh 
    ```
```

## Verify installation

<Warning>
**Python SDK Required**: To verify your installation, you need to have the VectorAI Python SDK installed. Install it using `pip install actian-vectorai-client` or follow the [Python SDK quickstart](/sdks/python/quickstart).
</Warning>

Test your installation by checking the server health:

```python
import asyncio
from actian_vectorai_client import AsyncVectorAIClient, VectorParams, Distance

async def main():
    async with AsyncVectorAIClient("localhost:6574") as client:
        info = await client.health_check()
        print(f"Connected to {info['title']} v{info['version']}")

asyncio.run(main())
```

## Troubleshooting

### Common issues

The table below lists common installation issues and their solutions.

| Issue                | Solution                                                        |
|----------------------|-----------------------------------------------------------------|
| Connection failed    | Ensure Docker container is running: `docker ps` |
| Port already in use  | Stop services using port 6574 or use a different port: `-p 6576:6574` |
| Permission denied    | Run Docker commands with appropriate permissions or add user to docker group |
| Container exits      | Check logs: `docker logs <container-id>` |

### View Docker logs

Check container logs for errors:

```bash
# List running containers
docker ps

# View logs
docker logs <container-id>

# Follow logs in real-time
docker logs -f <container-id>
```
